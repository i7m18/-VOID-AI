# VOID AI

مشروع تطبيق Android باسم VOID AI.

## الحالة الحالية
- تمت إضافة ملفات مشروع Android Kotlin وJetpack Compose.
- واجهة المحادثة عربية وبتصميم داكن.
- إعداد GitHub Actions لبناء نسخة APK تجريبية ورفعها كـ Artifact.
- **تنبيه:** هذه نسخة واجهة أولية؛ الردود حالياً تجريبية ولا يوجد اتصال فعلي بمحرك ذكاء اصطناعي بعد.

## بناء APK
من تبويب Actions شغّل workflow باسم **Build VOID AI APK**، وبعد نجاحه نزّل artifact باسم `VOID-AI-debug-apk`.
